# Future work: anonymous reporting

Anonymous reporting (a confidential route for reporting unfair assessments, with an anonymiser, case keys, a
triage model, evidence cleaning and a two-way conversation) was built and then removed from this version to
keep the scope focused. The code, its tests and its evaluation are in the git tag `with-anonymous-reporting`.
